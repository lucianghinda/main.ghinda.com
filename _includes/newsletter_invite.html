{% comment %} Newsletter invite. Rendered once at the end of every page from _layouts/default.html, using the `newsletter:` block in _config.yml. Plain GET form on purpose. The site ships no JavaScript beyond the theme toggle, and a provider iframe would be the only element on the page that cannot follow the dark theme. So the form just hands the address to beehiiv as a query parameter and lets the reader confirm there (beehiiv uses double opt-in anyway, so nothing is saved on submit either way). If beehiiv ever stops prefilling, the reader still lands on the subscribe page and types the address — the worst case is one extra keystroke set, not a dead button. Flat block, not a card: this theme is near-monochrome with no cards or shadows, so the invite uses the same amber left rule as blockquotes and the eyebrow style of the home-page section labels. Uses a fixed element id, so include it at most once per page. Params: hook optional eyebrow line above the name ("Enjoyed this article?") utm_medium attribution value passed through to beehiiv (default "site") {% endcomment %} {%- assign nl = site.newsletter -%} {%- if nl and nl.action %}
